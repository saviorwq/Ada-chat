Ada Chat 前端彻底模块化 — 迁移路线图
Full modularization roadmap (keep all features)

================================================================================
目标 / Goals
================================================================================
1. 以 ES Modules + Vite 管理全部前端代码，替代 AI.php 中多文件 <script> 顺序加载。
2. 生产环境由 PHP 读取 manifest 注入单包（或按 chunk），行为与现网一致。
3. 精简版（vchat）与完整版共享 src/shared 工具层，避免两套 escapeHtml 等逻辑长期分叉。

================================================================================

- full-app-entry.js + full.html：完整版 ESM 入口占位，npm run dev 可打开 /full.html 验证
- jsconfig.json：编辑器路径解析

【D-4 / 仅 Vite】已移除根目录 adachat-*.js、build:legacy-shims、src/shims；AI.php 仅 dist full 单包，无 dist 则 503。
