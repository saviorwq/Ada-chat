## 封口条件（v1.4 → Stable Candidate）

> **v1.3 = 能力闭环完成；v1.4 = 故障闭环开始完成。**  
> 原则：失败必须是**可见、可解释、可恢复**的状态，而不是转圈的 UI。

```text
v1.4 Harden
       ↓
T1–W5（含跨链路「地狱模式」）
       ↓
全部通过（本矩阵无 ⬜ / 无未关闭 ❌）
       ↓
回归测试 + 构建
       ↓
v1.4 Stable Candidate
       ↓
冻结核心架构 → 新能力进 v1.5
```

**地狱模式（跨链路状态机，必测）**

```text
LLM → Tool Calling → Tool 执行 → RAG citation → 流式回答 → worker/网络异常
```

单项通过 ≠ 跨链路收口。重点盯：Tool 异常后能否结束一轮；G1 流式中引用不消失；G2 中文/Tool 引用完整；W2 空流/spawn/worker 死可恢复；W3–W5 失败后彻底收口、不无限转圈。

封口后：**不再以「还有几个小 bug」继续堆功能**；缺陷进 v1.4.x 补丁或 v1.5，核心架构冻结。
