## 重点更新 / Highlights

- **🎵 本地音乐（ACE-Step 1.5）**：文生音乐、Cover 伴奏、Demucs 多轨 ZIP。
- Music worker **脱离 Job Object**，稳定连接本机 `:8001`。
- Cover **再生成 / 源音频过期**体验加固。
- 本地图像：人物脸部预设、Z-Image/SD/SDXL、Runtime 协同继续增强。

## 升级建议 / Upgrade Tips

- `npm run build` + Ctrl+F5。
- ACE `/health` ok 后再发 Cover；生成中勿点「释放显存」。
- 多轨需 `tools/demucs/setup.ps1`。

## 相对 v1.2.0

v1.2.0 奠定 Vite 单包与 Image Runtime；v1.3.0 补齐 **音乐创作闭环** 并巩固本地图像生产路径。
