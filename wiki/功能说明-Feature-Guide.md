# 功能说明 / Feature Guide

## 对话区主流程

1. 先选分类（对话/编程/图像等）
2. 再选供应商与模型
3. 输入问题并发送
4. 根据回复继续追问（系统会自动带上历史）

## 任务分类

- `💬 对话`：通用问答
- `💻 编程`：代码生成/修复
- `🎨 图像生成`：文生图/图生图（可走云端供应商，或本地 Diffusers Image Runtime）；本地支持 **人物脸部预设锁脸**（设置里保存正脸，工具栏选用，无需每次上传脸图）
- `🎬 视频生成`：云端/本地视频任务（若已启用）
- `📄 OCR`：提取图片/PDF文字
- `👁️ Vision`：看图分析
- `🌐 翻译`：文本或图片翻译
- `🎵 音乐生成`：本地 **ACE-Step 1.5** 文生音乐；**Cover 伴奏**（Suno WAV 蓝本 → 纯配器 → DAW 贴人声）。详见 `docs/music-generation.md`

## Windows 启动方式

- `启动 Ada Chat.bat`：带控制台，便于看日志
- `AdaChatTray.bat`：系统托盘启停，无黑色窗口
- 安装包版本：`AdaChat_Setup_v1.2.0.exe`（v1.3.0 能力见源码 / `RELEASE_NOTES_v1.3.0.md`；新安装包待发）

## 设置页核心

- 供应商与模型：新增供应商、拉取模型、保存选择
- 对话能力：预设、RAG、模式矩阵、单词转换、**人物脸部预设**、聊天身份、模型总设置
- 界面系统：语言、皮肤、成本优化、自动切换
- 安全开发：密码、插件、调试

### 本地音乐（ACE-Step）

- 文生音乐：风格 Prompt + 可选「歌词：」分段；可选手填 BPM / 步数 / CFG / LM 温度 / ODE。
- Cover 伴奏：上传源曲 → 纯配器；完成后可 **导出多轨(DAW)**（需 Demucs）。
- 详解：`docs/music-generation.md`；FAQ 见「本地音乐 / Cover」。

### 人物脸部预设（本地图像）

- 一次保存清晰正脸 → 之后文生图/图生图下拉选用即可锁脸。
- 与「角色预设」（提示词风格）不是一回事：前者管脸，后者管文案风格。
- 详解：`docs/face-identity-character-library.md`、`docs/v1.5-local-image-runtime.md`

## 模型总设置（新手重点）

- `temperature`：控制“发散度”。越低越稳，越高越有创意。
- `top_p`：控制“采样范围”。一般和 `temperature` 二选一微调即可。
- `max_tokens`：单次回复最大长度上限。留空表示走模型默认/系统策略。
- `presence_penalty`：鼓励聊“新点子”。值高时更容易跳出原话题。
- `frequency_penalty`：减少重复表达。值高时更不容易复读。
- `stop`：命中终止词后立刻停止输出（每行一个）。

### 新手推荐起步值

- 通用聊天：`temperature=0.7`，`top_p=1`，其余保持默认
- 写代码：`temperature=0.2~0.5`，减少随机性
- 创意文案：`temperature=0.8~1.0`，可适当提高发散

## 回答下方快捷操作

- `📋` 复制整条回答
- `🔄` 重回答（含文生图 / 音乐 Cover）
- 音乐：下载整曲、导出多轨(DAW)、仅人声、仅伴奏
