║          Ada Chat - 使用说明                ║
╚══════════════════════════════════════════════╝

【系统要求】
    - Windows 8.1 / 10 / 11（仅支持 64 位系统）
    - Visual C++ 运行库（安装程序会自动检测并安装）

【默认登录密码】
    admin123
    （仅当不存在 ai_data/.auth_password 且未设置环境变量 ADA_LOGIN_PASSWORD 时生效）

【首次使用请务必修改密码】
    推荐两种方式（二选一）：
    1) 登录后打开「设置」→「安全」→ 设置访问密码（会保存到 ai_data/.auth_password）
    2) 或设置环境变量 ADA_LOGIN_PASSWORD（更适合服务器部署）

【启动方式（只点一个文件）】
    安装完成后，在安装目录里找到并双击：「启动 Ada Chat.bat」
    （开始菜单 / 桌面上的 "Ada Chat" 快捷方式也是点它，效果相同）。
    会自动打开浏览器访问 http://127.0.0.1:8920/login.php
    若仍习惯旧文件名，双击 start.bat 也可以（内部会转调到上面这个）。

【绿色免安装 + 托盘图标（推荐）】
    把整个程序文件夹复制到任意位置（U 盘也可以），无需再运行安装程序。
    双击「AdaChatTray.bat」：无黑色命令行窗口，任务栏右下角会出现 Ada Chat 图标
    （若看不到，请点击托盘区的 ^ 展开）。
    右键图标：可再次打开浏览器，或「停止服务并退出」。
    若提示「已在运行」，说明服务已启动，到托盘区找图标即可。
    （需要 Windows 10 及以上自带的 PowerShell。）

【停止服务】
    若用「启动 Ada Chat.bat」开的：在黑色窗口里按 Ctrl+C，或双击「停止 Ada Chat.bat」。
    若用「AdaChatTray.bat」托盘开的：右键托盘图标 → 停止服务并退出。
    开始菜单里的「停止 Ada Chat」或 stop.bat 也可结束本机 PHP 进程。

【网页界面需要懂技术吗？不需要】
    用本程序自带的 Windows 安装包安装的用户：
        不用知道 Vite、npm、dist、单文件打包等任何名词，也无需安装 Node.js。
        安装 → 启动 → 浏览器里登录 → 按下面「首次配置」操作即可。
    只有「从 GitHub 等下载源码、自己拷到服务器上跑」的开发者才需要在电脑里
        安装 Node.js，并在源码目录执行 npm install 与 npm run build（否则会提示尚未构建）。
        这类说明写在 README 里是给维护人员看的，不是给日常用户看的。

【首次配置】
    1. 登录后点击 ⚙️ 设置 → ➕ 新增供应商
    2. 填入 AI 供应商名称、API 地址和 Key
    3. 点击「获取最新模型」→ 勾选需要的模型 → 保存
    4. 进入「模型类型管理」为模型分配类型
    5. 开始对话！
